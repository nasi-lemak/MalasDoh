The first release of MalasDoh: an SSH terminal, SFTP file browser and safe
remote editor in one native app for Windows, Linux and macOS. No Electron,
no PuTTY or OpenSSH needed.

### Editing files on servers without breaking them

- A diff before every save, and a refusal to overwrite a file someone else
  changed meanwhile (with a merge view).
- Backups of every save, a change journal of everything saved, and config
  checks before keeping a change (`nginx -t`, `visudo`, `sshd -t` and your own).
- Edit as root through sudo, edit one file on many servers at once, apply a
  patch, compare files across servers.

### Connecting

- Password, keys (including keys pasted in and kept in the system keychain),
  OpenSSH certificates, keyboard-interactive and one-time codes.
- Jump hosts, SOCKS/HTTP proxies and ProxyCommand, plus a built-in WireGuard
  tunnel and Teleport login (no `tsh` needed), with Teleport's servers and
  Windows desktops found for you.
- Remote Desktop to Windows machines through any connection, in your own
  RDP program.
- Port forwarding, agent forwarding, lasting terminals that survive a
  dropped connection, typing into several terminals at once.

### Files

- Two panes (your computer and the server) with drag and drop, a transfer
  queue with pause, resume and checksum checks, and "Replace files?" showing
  what would change.
- Rename, delete (to the Recycle Bin), new folder, permissions, owner,
  archives, find files, follow logs.

### Keyboard

Shortcuts throughout: switch connections and tabs, find a connection, file
lists that work like Explorer's, Enter and Esc in every dialog. Press **F1**
for the list.

### Downloads

- **Windows:** the `.zip`, or the `-portable.zip` that keeps everything in a
  folder next to the program.
- **Linux:** the `.deb`, or the `.tar.gz`.
- **macOS:** the universal `.dmg` (Apple Silicon and Intel).

The builds are not code-signed yet: Windows SmartScreen asks before the first
run ("More info", then "Run anyway"), and on macOS right-click the app and
choose Open. `SHA256SUMS.txt` lists the checksums of every file.
